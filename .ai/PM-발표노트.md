# PM 발표 노트 (러닝 기록용)

> 이 문서는 **발표 대본이 아니라 "재료 창고"** 입니다.
> 개발하거나 AI와 대화하다가 "이건 발표에 쓰면 좋겠다" 싶은 걸 그때그때 아래 해당 칸에 던져 넣으세요.
> 나중에 PPT / 발표 대본 만들 때 이 문서만 보고 뽑아 쓰는 게 목표입니다.
>
> **작성 규칙**
> - 완성된 문장 아닐 것: 키워드 / 짤막한 메모 / 링크 / 캡처 위치만 남겨도 됨
> - 발표에 실제 쓸 만한 건 `🎤` 태그, 그냥 참고용은 `📌`, 아직 확인 필요는 `❓`
> - 근거(수치·캡처·커밋·PR·이슈 링크)를 같이 남겨두면 발표 때 신뢰도가 올라감
> - 채우지 못한 칸은 비워둬도 됨 (모든 소제목을 다 채울 필요 없음)
