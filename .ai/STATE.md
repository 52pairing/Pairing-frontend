## API 관련 내용

- 이번 작업은 UI 구현만 포함하며 회원가입 API는 연동하지 않습니다.
- 사업 분야, 직원 수, 은행, 약관은 디자인 확인용 고정 데이터를 사용합니다.
- 이메일 인증과 중복 확인은 네트워크 요청 없이 로컬 상태만 변경합니다.
- 실제 API 연동 시 임시 데이터와 로컬 동작을 교체해야 합니다.

### 빌드 실패 내용

- `/login` 페이지의 `useSearchParams()`가 Suspense 경계 안에 없어서 prerender 단계에서 실패했습니다.
- 회원가입 변경이 아닌 최신 `develop`에 병합된 로그인 화면에서 발생한 오류입니다.
- 회원가입 페이지 컴파일과 TypeScript 검사는 통과했습니다.

## 주의사항

- 회원가입 API 서비스 파일은 이번 PR에 포함하지 않습니다.
- 로그인 API 연동 코드는 `develop`에서 상속된 내용이며 회원가입 PR 변경분이 아닙니다.
- commit, push, Pull Request 생성은 사용자의 명시적인 요청 없이 수행하지 않습니다.
