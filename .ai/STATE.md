# STATE

이 문서는 현재 AI와 함께 진행 중인 한 가지 작업만 기록합니다.

## 현재 작업

- 작업명: SVG 시안 기반 클라이언트 리뷰 작성 화면 구현
- 관련 Issue: 확인 필요
- 관련 브랜치: 현재 작업 브랜치
- 작업 목적: 전달받은 기본·입력 상태 시안을 클라이언트 리뷰 작성 경로에 동일하게 반영합니다.

## 이번 작업 범위

- `/client/projects/[projectId]/review` 리뷰 작성 UI
- 클라이언트·서비스 별점 선택
- 선택 리뷰 입력과 500자 카운터
- 필수 별점 선택에 따른 등록 버튼 활성화
- lint, build, 화면 확인

## 진행 상황

- [x] 프로젝트 규칙과 기존 리뷰 작성 구조 확인
- [x] SVG 시안 2종 렌더링 및 기본·입력 상태 확인
- [x] 시안 기준 평가 대상 문구 반영
- [x] lint 및 build 통과
- [ ] 브라우저 화면 확인 — 로컬 주소 접근 권한 거부로 미실행

## 주의사항

- 디자인 구현만 요청받아 리뷰 등록 API는 연동하지 않습니다.
- 프로젝트·사용자 표시는 시안의 예시 문구를 사용합니다.
- 기존 작업 트리의 프리랜서 프로필 등록 관련 변경은 수정하지 않습니다.
- SVG 원본을 PNG로 렌더링해 기본·입력 상태를 확인했으며, 실제 앱 브라우저 화면은 미확인입니다.
- 작업명: 클라이언트 프로젝트 관리 단위·컴포넌트 테스트 작성
- 관련 Issue: 확인 필요
- 관련 브랜치: 현재 브랜치 사용 중
- 작업 목적: 프로젝트 목록·상세·계약·진행 현황의 핵심 사용자 흐름을 Jest와 React Testing Library로 검증합니다.
