- 현재 사용자 API에는 이름과 이메일만 있어 기업명·사업자등록번호·사업 분야·직원 수·휴대폰 번호는 추측하지 않습니다.
- 실제 계정 및 비밀번호 변경 API 성공 응답은 테스트 계정이 없어 미검증으로 기록합니다.
- 비로그인 브라우저 확인은 인증 가드의 접근 권한 확인 화면(로그인 화면 리다이렉트)까지만 확인했습니다.
- 검증 중 `MyPagePasswordChange.tsx`의 비밀번호 검사 규칙이 프로젝트 확정 정책(대소문자 모두 포함)과 달라 `NewPasswordForm.tsx`/`SignupPasswordFields.tsx`와 동일하게 맞췄습니다.
- 기업 프로필 조회·수정 API는 확인되지 않아 저장 결과는 화면 상태에만 임시 반영합니다.
- 리뷰 조회 API는 현재 담당 범위에서 제외되어 시안 목업 데이터로 표시합니다.
- 결제수단 조회 API는 연결했으며 수정 API는 확인되지 않아 수정 결과를 화면 상태에만 임시 반영합니다.
- 회원탈퇴 가능 여부 및 탈퇴 API가 없어 실제 계정 삭제와 로그아웃은 수행하지 않습니다.
