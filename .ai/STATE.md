# STATE

이 문서는 현재 AI와 함께 진행 중인 한 가지 작업만 기록합니다.

## 현재 작업

- 작업명: 클라이언트 프로젝트 추천 후보 더미 화면 구현
- 관련 Issue: 확인 필요
- 관련 브랜치: 현재 브랜치
- 작업 목적: 프로젝트 상세의 추천 후보 탭에 더미 후보, 요청·거절·프로필 확인 흐름을 구현합니다.

## 이번 작업 범위

- 추천 후보 더미 카드와 포지션별 화면 추가
- 매칭 요청·추천 거절 확인 모달과 완료 알림 추가
- 후보 프로필 확인과 저적합 후보 안내 상태 연결

## 주의사항

- 추천 후보 데이터와 요청·거절 결과는 현재 프론트엔드 로컬 상태로만 동작합니다.
- 새 API 연동은 포함하지 않았습니다.
- commit, push, Pull Request 생성은 사용자 요청 없이 수행하지 않습니다.

- 약관 문서 조회 및 인증 만료·발송 제한 오류 처리를 보완했습니다.
- 정적 검증과 전체 빌드는 통과했으며 실제 인증 API 응답은 미검증입니다.
