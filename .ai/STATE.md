# STATE

이 문서는 현재 AI와 함께 진행 중인 한 가지 작업만 기록합니다.

## 현재 작업

- 작업명: 클라이언트 프로젝트 등록·목록 UI 축소
- 관련 Issue: 확인 필요
- 관련 브랜치: 현재 브랜치
- 작업 목적: 프로젝트 등록 위저드의 전체 크기를 줄이고 내 프로젝트 목록을 2열의 compact 카드 UI로 개선합니다.

## 이번 작업 범위

- 프로젝트 등록 공통 컨테이너 폭과 내부 여백 축소
- 등록 스텝퍼 크기와 단계별 상단 여백 축소
- 기본 정보·직군 모집·상세·검수·최종 확인 화면 밀도 개선
- 내 프로젝트 목록 단일 열 compact 카드 구성
- 목록 카드 제목·태그·정보·버튼 영역 compact 재배치
- 긴 제목·직무·스킬의 말줄임 및 초과 스킬 수 표시

## 주의사항

- API 요청, 응답 타입과 버튼 동작은 변경하지 않았습니다.
- 프로젝트 목록은 모든 화면 크기에서 카드가 한 줄에 하나씩 표시됩니다.
- 카드 스킬은 최대 3개만 표시하고 나머지는 `+N`으로 요약합니다.
- commit, push, Pull Request 생성은 수행하지 않습니다.
