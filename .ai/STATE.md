# STATE

이 문서는 현재 AI와 함께 진행 중인 한 가지 작업만 기록합니다.

## 현재 작업

- 작업명: 프리랜서 내 계약 페이지 구현
- 관련 Issue: 확인 필요
- 관련 브랜치: 확인 필요
- 작업 목적: 기존 역할별 페이지 구조를 따라 프리랜서 계약 목록을 상태별 하드코딩합니다.

## 현재 작업 범위

- 내 계약 상태 탭과 필터
- 서명·진행·정산·완료·중도 종료 계약 카드
- 상태별 배지, 안내 및 액션 UI
- 모바일·데스크톱 반응형 레이아웃

## 확인이 필요한 내용

- 실제 결제 API는 미연동이며 등록 카드와 결제 결과는 하드코딩 상태입니다.
- 계약 데이터는 전달받은 시안을 기준으로 한 하드코딩 데이터입니다.

## 주의사항

- 환경변수 실제 값은 문서와 Git에 기록하지 않습니다.
- 실제 응답을 확인하기 전까지 API 항목은 `미검증`으로 기록합니다.
- commit, push, Pull Request 생성은 사용자 요청 없이 수행하지 않습니다.
