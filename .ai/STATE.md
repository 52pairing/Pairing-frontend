## 이번 작업 범위

- 공통 역할 접근 가드 구현
- `/client/*`는 `CLIENT`, `/freelancer/*`는 `FREELANCER`만 허용
- 비로그인(401)은 로그인 화면으로 이동
- 역할 불일치는 `/forbidden`으로 이동
- 사용자 조회의 네트워크·서버 오류는 재시도 화면 제공
- 기존 404 디자인과 일관된 403 화면 및 역할별 홈 버튼 구현
- 기존 프로젝트 등록 전용 역할 가드 중복 제거
